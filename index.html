How this works

  • The map is precomputed offline: UMAP of the SigLIP2 vectors of rows 0-24,999; the region names come from their captions. It is a 100 KB file shipped with this page: 25,000 points of two 16-bit coordinates.
  • Every caption and image is fetched live from Hugging Face with HTTP Range requests, by nanolance running in a Web Worker. Six workers each open the dataset once; a click spreads its rows across the idle ones.
  • The dataset's single 48 GB data file is never downloaded. Only the bytes of the rows you click are fetched.
  • The numbers on this page are measured in your browser, not estimated.
